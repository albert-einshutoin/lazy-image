`darwin-x64`はMach-O arm64、`linux-arm64-gnu`はELF x86-64、`linux-x64-musl`は

`postbuild-fixup.js`へtarget引数を渡してしまい、`napi build`はhost向けとなる可能性が高い。
この原因は#850で修正時に確定する。v1.3.0は変更できないため、今後の修正版の結果を
別version・revisionで記録する。**10組を実行済みだが全環境の検証完了ではない。**
