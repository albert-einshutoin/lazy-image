### 2026-09-23: 残りnative platformの公開npm smoke

上の表と「残作業」は前回調査時点の記録。今回の検証には
[`registry-native-smoke.cjs`](../../scripts/registry-native-smoke.cjs) と

platform packageのversion・tarball・integrityをregistry metadataとlockfileで照合する。

CLI binがインストール先にあることを確認する。上記fixture/policyでAPI・CLI双方から
2つのWebPを生成し、形式・寸法・bytes・SHA-256・manifest一致までassertする。
PASSは全assert成功のみ。公開物を実行して失敗した環境はFAIL、runner等を確保できず
実行前に止まった環境はBLOCKEDとする。
