# v1.3.1 native release verification

v1.3.0 の公開npm packageは darwin-x64、linux-arm64-gnu、linux-x64-musl の両Nodeで実際のbinding loadに失敗した。この結果は[元の検証記録](V1.3.0_VERIFICATION.md)と[#850](https://github.com/albert-einshutoin/lazy-image/issues/850)に残す。v1.3.1 は別の公開物として、候補tarballと公開後registry installを別々に判定する。

## 修正と再発防止

[PR #851](https://github.com/albert-einshutoin/lazy-image/pull/851)を `ec3601e03495c77203c94c0bc84f2b52da6e89ae` でmerge。`--target`をnapi/Cargoへ直接渡し、macOS x64とLinux arm64 GNUはCPU一致のrunnerで、Linux x64 muslはUbuntu x64 host上のAlpine x64 containerとRust 1.88.0 musl toolchainでビルドする。CPUエミュレーションは使用しない。

候補収集時にtargetごとのartifactを1個だけ許し、package名・ファイル名・binary形式/CPU・Linuxの必要ライブラリとGLIBC参照を検査する。7 tarballのSHA-256と中のbinary hashをmanifestに固定し、候補の12組smokeおよびfull CIがすべて成功するまでpublish jobを開始しない。[失敗したdry run](https://github.com/albert-einshutoin/lazy-image/actions/runs/35891772404)では、Ubuntu上のcross-buildで生成したmusl名のbinaryにGLIBC依存が残り、検査が公開前に拒否した。これはv1.3.0の公開後FAILおよび修正版のsmokeとは別の履歴。

## v1.3.1 tagの候補

[tag CI run 35896641912](https://github.com/albert-einshutoin/lazy-image/actions/runs/35896641912)はmerge commit `ec3601e03495c77203c94c0bc84f2b52da6e89ae` から候補を再生成した。保存された`release-candidate/manifest.json`のSHA-256は`f8205db485240f2f80361fa2b0ba9d1200c9a485e3f1160215651555dc5c3c11`。7 tarballの実体hashはmanifestと一致。PR dry runとsource treeは同じだが、一部binaryのhashはビルド間で異なるため、**公開判定にはtag runの候補と12組smokeを使用する**。公開後はこのmanifestに記録したtarballのSHA-512 integrityとnpm registryの`dist.integrity`を照合する。

tag run自身の`candidate-smoke-{platform}-node{major}` artifactを確認し、**12/12 PASS、FAIL/BLOCKEDなし**。全12 JSONでscript/candidate revisionはmerge commit、sourceは`candidate-tarball`。binding・API・CLI・成果物・API/CLI一致がそれぞれPASS。muslはUbuntu x64 host上のAlpine x64/muslで、Nodeプロセスのarch/libcを記録した。[main CI](https://github.com/albert-einshutoin/lazy-image/actions/runs/35895169125)、[main Security Audit](https://github.com/albert-einshutoin/lazy-image/actions/runs/35895169104)、[tag Security Audit](https://github.com/albert-einshutoin/lazy-image/actions/runs/35896642081)も成功した。

tag runのpublish jobは、この同じ`release-candidate` artifactの6 platform tarballと本体tarballを公開した。registry metadataで7 packageの`dist.integrity`がtag候補のSHA-512と一致することを確認した。Wasmも1.3.1として公開済み。[GitHub Release v1.3.1](https://github.com/albert-einshutoin/lazy-image/releases/tag/v1.3.1)はdraft/prereleaseではない。公開npmを通常installした動作検証は次節に分離する。
