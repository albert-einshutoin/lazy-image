## Version and distribution preparation

The existing `npm run version` synchronizes main optional platform references, Cargo.toml, and native npm lock entries. It does not cover every release file. Wasm package.json / shared.js VERSION, the npm workspace lock entry, Cargo.lock, and fuzz/Cargo.lock are checked separately. Only the lazy-image package version changes in both Cargo locks; unrelated npm lock entries and all dependency versions are retained. Canonical `npm run build` generates index.js/index.d.ts in an isolated checkout using the lock-matched N-API CLI; the existing root binding and other evaluation worktrees are preserved.

The existing installed-package smoke runner retains its no-budget two-width WebP API/CLI checks. Its added condition uses a 64 px WebP, a 1 MiB budget, and `maxQuality: 30`: lower and upper bounds coincide, so an implementation ignoring the ceiling and returning q100 fails. Both API and installed CLI must produce a verified manifest with q30 and matching bytes/hash. Invalid 29, 101, and string `"30"` must reject with E400 and leave no output or staging directory. The same runner serves candidate tarballs and later published npm installs. It introduces no timing threshold, separate distribution framework, fallback, or dependency.

## Verification and evidence boundaries

Targeted release/version/package/type/generated-file and new-smoke checks precede self-review and one high-risk specialist review. Related fixes receive final scoped review, then required complete validation and a fresh Codex Companion Stop Review Gate bind the final diff. The preparation PR merges only after final-HEAD required checks pass. Main CI and Security must succeed at the merge SHA.

The merged release commit is tested through a non-tag ref with CI.yml `full_validation=true` / `dry_run=true`. Dispatch ref and run headSha must equal that commit; the publish job must be skipped. Dry-run input alone does not prevent publication on a tag ref. Evidence requires all six actual native binaries with name/CPU/format/Linux libc inspection, main plus six platform tarballs and manifest SHA-256, full CI, and all six platforms × Node 22/24 (12) installed API/CLI smoke results including maxQuality. Wasm is packed from the same revision, and its version, content, and existing package checks are recorded separately. Candidate PASS is not published-registry PASS.

Failed or unavailable outcomes are retained. A revision-changing fix invalidates old revision proof and requires evidence bound to the new revision. Post-merge run results, manifests, tarball hashes, artifact download locations/expiry, and necessary retained copies are attached to this Issue/PR without another record-only PR.
